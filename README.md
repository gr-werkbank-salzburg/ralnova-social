# ralnova-social

Bilder und Wochenpläne für die Social-Media-Posts von Ralnova Connect (Facebook + Instagram, geplant über Metricool).

- `CONTENT.md` – Leitfaden: Themen, Abwechslung, Regeln, Ablauf
- `posts/plan/` – ein Plan pro Woche (Texte, Layout, Uhrzeit)
- `posts/<Monat>/` – fertige Bilder (öffentlich, werden von Metricool abgeholt)
- `tools/` – Render-Skript und Layouts

Hier nur Post-Bilder ablegen. Alles in diesem Repository ist öffentlich.
